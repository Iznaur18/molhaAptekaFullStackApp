# Возможности пользователей

Документ описывает права **обычного зарегистрированного пользователя** (`userRole: user`) по флагам в профиле.  
Роли **admin** и **moderator** — отдельно (модерация, staff-очереди, правка чужих профилей).

**Важно:** `isPremiumUser` и `isUserDataConfirmed` — **независимые** признаки. Пользователь может быть только премиум, только подтверждённым, обоими сразу или ни одним.

Общие условия для всех: аккаунт **не заблокирован** (`isBlockedUser !== true`), **активен** (`isActiveUser !== false`).

---

## База (любой зарегистрированный пользователь)

- Регистрация и вход по email.
- Редактирование своего профиля: ник, дата рождения, пол, адрес доставки, телефон, аватар, **фон только из пресетов** (без своего URL).
- Каталог: просмотр, поиск, фильтры по категории, подпискам, акциям, аукциону.
- Покупки: корзина, оформление заказа, «Мои заказы», подтверждение получения позиции.
- Продажи: создание и редактирование **одобренных** товаров, скрытие/показ в каталоге, удаление (если нет открытых продаж).
- Продвижение своих товаров (оплата **баллами** лояльности; стоимость пакета = ceil(номинал тарифа в ₽) × 2).
- Подписки на продавцов, лента подписок.
- Жалобы на товары.
- Просмотр чужих профилей, рейтинг пользователей.
- Заявка на **подтверждение данных** (паспорт → очередь staff), пока статус не подтверждён.

**Не доступно без премиум / подтверждения** — см. разделы ниже.

---

## 1. Обычный пользователь

`isPremiumUser: false`, `isUserDataConfirmed: false` (типичный новый аккаунт).

### Покупатель

| Возможность                           | Доступ                                              |
| ------------------------------------- | --------------------------------------------------- |
| Покупка товаров, заказы               | ✅                                                  |
| Баллы лояльности за покупку           | ❌ (начисление только подтверждённым покупателям)   |
| Отзыв на товар                        | ❌                                                  |
| Ставка на аукционе (предложение цены) | ❌                                                  |

### Продавец

| Возможность                         | Лимит / примечание             |
| ----------------------------------- | ------------------------------ |
| Товаров в каталоге                  | **до 15** одобренных           |
| Розыгрыш                            | ❌ создать нельзя              |
| Участие товаров в розыгрыше         | по правилам розыгрыша продавца |
| Продвижение товара                  | ✅ (рубли / баллы)             |
| Золотая обводка карточки в каталоге | ❌                             |
| Фильтр каталога «Только премиум»    | товары не попадают             |

### Профиль и UI

| Возможность                                       | Доступ                                          |
| ------------------------------------------------- | ----------------------------------------------- |
| Фон профиля                                       | только **пресеты**, не свой URL                 |
| Бейдж «подтверждён» у имени                       | ❌                                              |
| Список покупок **другого** пользователя в профиле | ❌                                              |
| Фильтр «Подтверждённые продавцы»                  | свои товары не попадают, пока нет подтверждения |

## 2. Премиум-пользователь

`isPremiumUser: true` (оформляется за баллы лояльности в профиле или назначается staff).

Всё из раздела «Обычный пользователь», **плюс:**

### Покупатель

| Возможность   | Детали                                                                 |
| ------------- | ---------------------------------------------------------------------- |
| Тратить баллы | ✅ например, продвижение товара (в 2 раза дороже номинала в ₽), премиум |

### Продавец

| Возможность         | Детали                                                 |
| ------------------- | ------------------------------------------------------ |
| Лимит товаров       | **до 30** одобренных                                   |
| Каталог             | товары видны в сортировке/фильтре **«Только премиум»** |
| Карточка в каталоге | **золотая обводка** (у чужих покупателей в ленте)      |

### Профиль

| Возможность     | Детали                                                                           |
| --------------- | -------------------------------------------------------------------------------- |
| Фон профиля     | ✅ можно указать **свой URL** (http/https), не только пресет                     |
| Галочка премиум | ✅ у имени в интерфейсе                                                          |
| Сторис          | ✅ публикация сторис                                                             |
| Чужие покупки   | ✅ премиум (и staff) видят **список покупок** другого пользователя в его профиле |

**Премиум не заменяет подтверждение данных:** без `isUserDataConfirmed` по-прежнему нельзя отзывы, аукцион-ставки, рассрочку, баллы за покупки и создать розыгрыш.

---

## 3. Подтверждённый пользователь

`isUserDataConfirmed: true` (после одобрения staff заявки с паспортными данными или ручной установки флага admin/moderator).

Всё из раздела «Обычный пользователь», **плюс:**

### Покупатель

| Возможность                | Условие                                                                                      |
| -------------------------- | -------------------------------------------------------------------------------------------- |
| Баллы лояльности           | ✅ после подтверждения покупателем позиции «Доставлен» → «Подтверждён»; размер задаёт продавец на товаре (`loyaltyPointsPerUnit`) |
| Отзыв на товар             | ✅ после **подтверждённой покупки** этой позиции                                            |
| Предложение цены (аукцион) | ✅ на чужих товарах с включённым аукционом                                                   |
| Покупка в рассрочку        | ✅ при одобренной программе на товаре                                                        |

### Продавец

| Возможность      | Детали                                                                          |
| ---------------- | ------------------------------------------------------------------------------- |
| Создать розыгрыш | ✅ в профиле кнопка «Создать розыгрыш» (один активный/на модерации на продавца) |
| Рассрочка        | ✅ включить программу на товаре (после модерации программы)                     |
| Каталог          | товары попадают в фильтр **«Подтверждённые продавцы»**                          |

### Профиль и доверие

| Возможность                       | Детали                                    |
| --------------------------------- | ----------------------------------------- |
| Бейдж подтверждения               | ✅ у имени (в каталоге, ставках, отзывах) |
| Повторная заявка на подтверждение | ❌ не нужна                               |

**Подтверждение не даёт премиум:** лимит 15 товаров, без золотой обводки, сторис и без чужих списков покупок — пока не включён премиум.

## Комбинации (кратко)

| Премиум | Подтверждён | Типичный сценарий                                                                                    |
| :-----: | :---------: | ---------------------------------------------------------------------------------------------------- |
|   ❌    |     ❌      | Новый пользователь                                                                                   |
|   ✅    |     ❌      | Премиум-продавец без KYC: больше слотов, фон URL, сторис; без отзывов/аукциона/розыгрыша/баллов     |
|   ❌    |     ✅      | Проверенный продавец/покупатель: отзывы, аукцион, розыгрыш, баллы за покупки; лимит 15, без премиум-бонусов |
|   ✅    |     ✅      | Полный набор покупательских и продавческих бонусов                                                   |

---

## Staff (admin / moderator) — справка

Не заменяют типы выше; это **роль** `userRole`:

- Модерация товаров, жалоб, заявок на подтверждение данных, продвижения, розыгрышей.
- Редактирование чужих профилей (блокировка, премиум, подтверждение, скидка, баллы).
- Admin: смена ролей, удаление пользователей, заказы всех продавцов.
