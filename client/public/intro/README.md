# Intro video

Положи сюда файлы для splash при первом заходе:

- `intro.mp4` — основной (обязательно для видео)
- `intro.webm` — опционально (лучше сжатие в Chrome/Firefox)
- `intro-poster.jpg` — постер до старта воспроизведения

Рекомендации: 3–10 сек, до ~5 MB, без звука в файле или со звуком (в UI звук включается кнопкой).

Без файлов показывается CSS-заглушка с логотипом.
