# Чеклист адаптации экранов (mobile)

Проверка на **2–3 устройства** + скриншоты узкого Expo web (~390px).

## Устройства

| Устройство | Ширина | Колонки каталога |
|------------|--------|------------------|
| Узкий Android (Samsung A) | ≤359dp | 2 |
| iPhone / стандартный телефон | 360–599dp | 3 |
| Планшет / широкое окно web | ≥600dp | 4 |

## Экраны

- [ ] **Каталог** — сетка 2/3/4, карточки не обрезают цену, `…` в названии ок
- [ ] **Деталь товара** — галерея ~58% высоты, скролл, табы, док (корзина + 2 shortcut)
- [ ] **Деталь <360dp** — shortcut-кнопки в колонку (2 ряда)
- [ ] **Профиль** — safe area, без налезания на таббар
- [ ] **Корзина** — итоги и кнопки читаемы
- [ ] **Модалки** (жалоба, промо, auth) — не выходят за края
- [ ] **Intro** — splash/hero без обрезки на 360dp
- [ ] **Expo web** — узкое окно ~390px, portrait-only в native

## Ориентация

Только **portrait** (`app.json` → `orientation: "portrait"`).

## Шрифты

На таббаре, табах детали, доке, ценах и бейджах — `allowFontScaling: false` (`AppText`).

## Не в этом заходе

- Переключатель темы в приложении — отдельная задача.
