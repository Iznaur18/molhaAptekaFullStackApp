## Обязательный порядок работ

### 1. Целостность баллов и заказов — MongoDB transactions (P0)

Сейчас резерв/списание баллов (`userLoyaltyPointsReserved`, `loyaltyPointsReserve.js`,
`makeOrderController`, `updateOrderItemStatusController` confirm) — несколько `updateOne` без транзакций.
При сбое между шагами — рассинхрон баланса и заказа.

Сделай:
- `mongoose.startSession()` + `withTransaction` (или эквивалент) для:
  a) создание заказа + резерв баллов продавца (`makeOrderController`, рассрочка в `installmentContractControllers` если там тоже заказ);
  b) подтверждение позиции покупателем: settle баллов продавец→покупатель + обновление item/order;
  c) отмена позиции/заказа: release резерва.
- При ошибке — полный rollback, без «висящего» резерва.
- Сохранить текущую бизнес-логику: премиум-only начисление, резерв = perUnit×qty с карточки на момент заказа, release при отмене.

Критерий приёмки:
- Симуляция/тест: если `OrderModel.create` падает после reserve — reserved откатывается.
- Двойной confirm одной позиции не даёт двойное начисление (идемпотентность `loyaltyPointsAwarded` сохранить и проверить).
